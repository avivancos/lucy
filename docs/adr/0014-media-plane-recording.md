# ADR 0014 - Media-Plane Recording

## Status

Accepted

## Context

Lucy needs call recording, transcript replay, and recording playback in the
platform dashboard, but ADR 0004 and ADR 0011 keep audio frames out of Python.
The SDK can coordinate consent, blob identifiers, and telemetry, while the media
plane owns the socket and the actual audio bytes.

## Decision

Recordings are produced by the media plane and referenced through control-channel
events and telemetry. Python may request recording start or stop, mint blob upload
targets, validate upload completion metadata, and emit `audio_ref` telemetry, but
it never receives raw caller or agent audio frames.

Recording support is additive to the control-channel schema:

- The gateway advertises capabilities in `SessionStarted.features`.
- Python sends `recording.start` and `recording.stop` directives.
- The media gateway reports `recording.started`, `recording.uploaded`, and
  `recording.failed` events.
- Each uploaded asset records leg, duration, byte count, hash, container, and
  consent reference.

The default SDK behavior remains no recording. `RecordingSpec.enabled` is false
by default, recording obeys the existing `record_audio` observability kill switch,
and blob uploads are suppressed for unsampled sessions unless a card explicitly
documents a different policy. The open SDK ships the coordination protocol and a
local blob-store simulator; hosted retention, erasure, signed playback URLs, and
cross-tenant recording search are platform concerns under ADR 0010.

## Consequences

- Platform dashboards can play recordings by dereferencing `audio_ref` and
  recording metadata, not by reading SDK-local audio bytes.
- Tests must prove the seam with deterministic WAV files generated by
  `LocalGatewaySimulator` and uploaded through real HTTP to a local blob server.
- The Rust gateway conformance fixtures must include recording messages once card
  70 lands, so card 51 waits for card 70.
- Consent lineage, retention, and erasure are explicit product surfaces, not
  implied side effects of storing audio.
